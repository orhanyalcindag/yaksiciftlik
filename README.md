# 🌾 Yakşi Çiftlik — Doğal Çiftlik Ürünleri & Canlı Sürü E-Ticaret Platformu

Kırklareli Demirköy Balaban Köyü'nde Istranca ormanlarının eteklerinde yer alan **Yakşi Çiftlik** için modern, sıcak ve samimi köy havasını yansıtan e-ticaret ve tanıtım web uygulaması.

---

## 🌟 Öne Çıkan Özellikler

- **Rustik & Doğal Tasarım:** Ahşap tonları (`#4A2E18`), zeytin/orman yeşili (`#2D5A27`), sıcak krem zeminler (`#FDFBF7`) ve altın sarısı detaylar ile otantik çiftlik estetiği.
- **Doğal Ürün Kataloğu:**
  - Günlük Köy Yumurtası, Ördek Yumurtası, Beç Tavuğu Yumurtası ve Yüksek Döllü Kuluçkalık Yumurta.
  - Damızlık Tavuk, Horoz, Yeşil Başlı Ördek, Beç Tavuğu, Civcivler ve Kuluçka Hizmeti.
  - Dinamik paket/adet seçenekleri (1 Adet, 15'li Viyol, 30'lu Koli vb.).
- **Kayar Sepet & WhatsApp Sipariş Çözümü:**
  - Müşteriler sepete ürün ekleyip adetleri güncelleyebilir.
  - "WhatsApp ile Sipariş Ver" butonu siparişi düzenli ve temiz bir şablonla doğrudan çiftlik WhatsApp hattına (`0536 258 83 76`) aktarır.
- **Yönetim Paneli (`/admin`):**
  - Kolay ürün yönetimi (Ekleme, Düzenleme, Silme, Stok Durumu).
  - Hızlı fiyat güncelleme tablosu.
  - Cihazdan fotoğraf seçip doğrudan yükleyebilme desteği.
- **%100 Mobil ve Masaüstü Uyumlu (Responsive):**
  - Instagram ve mobil ziyaretçiler için optimize edilmiş akıcı arayüz.

---

## 🛠️ Teknoloji Yığını

- **Framework:** Next.js 16 (App Router)
- **Kütüphane:** React 19
- **Stil & Tasarım:** Tailwind CSS v4
- **İkonlar:** Lucide React
- **Efektler:** Canvas Confetti

---

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim derlemesi (Build)
npm run build

# Üretim sunucusunu başlatın
npm start
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açarak uygulamayı görüntüleyebilirsiniz.
